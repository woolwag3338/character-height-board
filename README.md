# 立ち絵身長比較ボード

立ち絵を身長どおりの縮尺で横に並べて、キャラクター同士の背の高さを見比べるツール。

**▶ [https://woolwag3338.github.io/character-height-board/](https://woolwag3338.github.io/character-height-board/)**

インストールは要りません。上のリンクを開いて、立ち絵をドラッグ＆ドロップするだけです。
**画像はブラウザの中だけで処理され、どこにもアップロードされません。**

---

## できること

- **身長に合わせた自動縮尺**（名前と身長(cm)を入れるだけで、全員の縮尺が揃う）
- **透明な余白の自動除去**（絵の部分だけを見て高さを測る）
- **頭頂・足元ラインの調整**（獣耳、帽子、浮いている足元などに対応）
- **並べ替え**（左右は自由配置。等間隔に整列／身長順に整列のボタンもある）
- **重なり順の変更・複製・表示の切り替え**（複製は身長違いの比較に使える）
- **PNG 書き出し**（元画像の解像度を活かした高解像度で出力）
- **ファイルへの保存・読込**（`.hboard` 形式。画像も含めて 1 ファイルにまとまる）
- **自動保存**（次に開いたとき、前回の盤面が復元される）

## 使い方

![ツールの画面。身長の違う 3 体を並べたところ](screenshot.png)

1. 上のリンクを開く
2. 立ち絵の画像をウィンドウにドラッグ＆ドロップする
   - 複数枚をまとめて落とすと、一覧形式の入力ダイアログが出る
   - 名前の初期値には拡張子を除いたファイル名が入る
3. 身長(cm)を入力すると、その高さになるよう縮尺が揃えられる
4. ずれていたら、キャラを選択して**頭頂ライン／足元ライン**を調整する
5. 並べ終えたら **PNG 書き出し**、または `.hboard` で保存する

帽子や獣耳を身長に含めたくない場合は、頭頂ラインを頭のてっぺんまで下げてください。
「地面から頭頂ラインまで」が入力した身長になります。

## 画像の形式

**背景が透過された PNG または WebP を推奨します。**
透明な部分を除いた範囲を自動で見つけて、そこが指定した身長になるよう縮尺を合わせるためです。

**画像の周囲に透明な余白が残っていても、そのまま読み込んで構いません。**
余白は自動で除かれるので、あらかじめ切り詰めておく必要はありません。

次の場合だけ、**頭頂ライン・足元ラインを手で合わせる必要があります**。

| 画像 | 理由 |
| --- | --- |
| 透過されていない画像（JPEG など） | 余白ぶんも身長に含まれてしまう |
| 発光・ぼかし影・薄いオーラなど、半透明の効果がある立ち絵 | うっすら色が乗った部分も絵の一部として拾うため、頭頂ラインが光の上端に付く |

## 操作一覧

| 操作 | 動作 |
| --- | --- |
| ホイール | 拡大縮小（カーソル位置が基準） |
| Shift＋ホイール | 横スクロール |
| 空白をドラッグ | 表示位置を移動 |
| 中ボタンでドラッグ | 表示位置を移動（キャラの上からでも可） |
| キャラをドラッグ | 左右に移動（縦は床に固定） |
| 矢印キー | 選択中のキャラを微調整（Shift 併用で 10 倍） |
| 空白をクリック／Esc | 選択解除 |
| 倍率表示をクリック | 等倍（100%）に戻す |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Shift+Z` / `Ctrl+Y` | やり直す |

## プライバシー

- **読み込んだ画像はすべてブラウザ内で処理され、どこにもアップロードされません**
- 保存先も、手元のブラウザと書き出したファイルだけです
- アクセス解析のため [Google Analytics](https://policies.google.com/technologies/partner-sites) を使っています。
  ページの閲覧状況（アクセス日時・参照元・ブラウザの種類など）が Google に送信されますが、
  **画像やファイル名が送信されることはありません**

同じ内容は、ツール内の「その他」メニュー →「このツールについて」からも読めます。

## 動作環境

- Chrome / Edge / Firefox / Safari の新しめのバージョン
- JavaScript が有効であること
- インストール・アカウント登録は不要
- 自動保存にブラウザの保存領域を使います。プライベートウィンドウなどで使えない場合は、
  自動保存だけが無効になります（他の機能は動きます）
- 書体はネット経由で読み込みます。読めない環境では端末の書体になりますが、機能は変わりません

### オフラインで使う

このページの `index.html` を保存すれば、ダブルクリックで開いて使えます。
その場合、アクセス解析の通信も発生しません。ただし自動保存は使えなくなることがあります。
