# 立ち絵身長比較ボード

立ち絵を身長どおりの縮尺で横に並べて、キャラクター同士の背の高さを見比べるツール。

**▶ [https://woolwag3338.github.io/character-height-board/](https://woolwag3338.github.io/character-height-board/)**

インストールは要りません。上のリンクを開いて、立ち絵をドラッグ＆ドロップするだけです。

**画像はブラウザの中だけで処理され、どこにもアップロードされません。**

---

## できること

- **身長に合わせた自動縮尺**（名前と身長(cm)を入れるだけで、全員の縮尺が揃う）
- **透明な余白の自動除去**（絵の部分だけを見て高さを測る）
- **頭頂・足元ラインの調整**（獣耳、帽子、浮いている足元などに対応）
- **並べ替え**（左右は自由配置。等間隔に整列／身長順に整列のボタンもある）
- **重なり順の変更・複製・表示の切り替え**（複製は身長違いの比較に使える）
- **PNG 書き出し**（元画像の解像度を活かした高解像度で出力）
- **盤面の保存・読み込み**（`.hboard` 形式。画像も含めて 1 ファイルにまとまる）
- **自動保存**（次に開いたとき、前回の盤面が復元される）

## 使い方

![ツールの画面。身長の違う 3 体を並べたところ](screenshot.png)

1. 上のリンクを開く
2. 立ち絵の画像をウィンドウにドラッグ＆ドロップするか、画面左の「追加」（キャラがいないときは盤面の「キャラを追加」）から選ぶ
   - 複数枚をまとめてドロップすると、「キャラをまとめて追加」の画面でまとめて身長を入れられる（身長が空欄の行は追加しない）
   - 名前の初期値には拡張子を除いたファイル名が入る
3. 身長(cm)を入力すると、その高さになるよう縮尺が揃えられる
4. 頭頂や足元の位置がずれていたら、キャラを選択して**頭頂ライン／足元ライン**を調整する
5. 並べ終えたら **PNG 書き出し**、または ⋯ メニューの **盤面を保存**（`.hboard`）

初めて開くと、練習用の人型で操作を順に案内するチュートリアルが出ます（いつでも飛ばせます）。あとから見直すときは、右上の「？」（ヘルプ）の「チュートリアルをもう一度見る」から開けます。

帽子や獣耳を身長に含めたくない場合は、頭頂ラインを頭のてっぺんまで下げてください。「床から頭頂ラインまで」が入力した身長になります。

かがんだポーズや胸から上だけの立ち絵は、頭頂ライン・足元ラインを盤面でドラッグして**絵の外まで**動かすと、立った時の身長のまま比べられます（頭頂は絵より上、足元は絵より下へ）。

### 保存の手段

立ち絵を入れるのは、**画像のドラッグ＆ドロップ**か **「追加」ボタン**から行えます。盤面そのものの保存・読み込みは、右上の **⋯ メニュー**の中にあります（「盤面を開く」は立ち絵を入れるためのものではありません）。

|                                   | 何をするか                           | いつ使うか                        |
| --------------------------------- | ------------------------------- | ---------------------------- |
| 自動保存                              | 今の盤面をブラウザに保存（**保存する盤面は 1 つだけ**） | 何もしなくてよい。次に開くと前回の盤面が戻る       |
| **盤面を保存** / **盤面を開く**<br>（⋯ メニュー） | 画像ごと 1 ファイル（`.hboard`）にまとめる     | 複数の盤面を持ち回す／別の端末へ移す／バックアップを取る |
| **PNG 書き出し**                      | 立ち絵を並べた盤面を画像として出力する             | 完成したものを投稿・共有する               |

保存した `.hboard` は、メニューの「盤面を開く」からだけでなく、**盤面にドラッグ＆ドロップしても開けます**。

**PNG から盤面には戻せません。** 別の端末へ移すときやバックアップを保存するときは、⋯ メニューから `.hboard` として保存してください。

### 自動保存の注意

自動保存はブラウザに預けているだけなので、次の場合に消えます。

- ブラウザの「Cookie とサイトデータ」を消したとき
- プライベートウィンドウ（シークレットモード）を閉じたとき
- Safari で、ブラウザを使った 7 日の間に一度もこのページを開かなかったとき

また、**自動保存できる盤面は 1 つだけ**です。別の盤面を作ると前のものは上書きされます。**残したい盤面は `.hboard` として保存してください。**

## 画像の形式

**背景が透過された PNG または WebP を推奨します。** 透明な部分を除いた範囲を自動で見つけて、そこが指定した身長になるよう縮尺を合わせるためです。

**画像の周囲に透明な余白が残っていても、そのまま読み込んで構いません。** 余白は自動で除かれるので、あらかじめ切り詰めておく必要はありません。

次の場合だけ、**頭頂ライン・足元ラインを手で合わせる必要があります**。

| 画像 | 理由 |
| --- | --- |
| 透過されていない画像（JPEG など） | 余白ぶんも身長に含まれてしまう |
| 発光・ぼかし影・薄いオーラなど、半透明の効果がある立ち絵 | うっすら色が乗った部分も絵の一部として扱うため、頭頂ラインが光の上端に付く |

## 操作一覧

| 操作 | 動作 |
| --- | --- |
| ホイール | 拡大縮小（カーソル位置が基準） |
| Shift＋ホイール | 横スクロール |
| 空白をドラッグ | 表示位置を移動 |
| 中ボタンでドラッグ | 表示位置を移動（キャラの上からでも可） |
| キャラをドラッグ | 左右に移動（縦は床に固定） |
| `.hboard` をドロップ | 保存した盤面を開く（今の盤面と置き換わる） |
| 矢印キー | 選択中のキャラを微調整（Shift 併用で 10 倍） |
| 空白をクリック／Esc | 選択解除 |
| 倍率表示をクリック | 等倍（100%）に戻す |
| 盤面と右のパネルの境目をドラッグ | パネルの幅を変える（ダブルクリックで元の幅に戻す。PC のみ） |
| 「キャラ設定」の見出しをクリック | キャラ設定をたたむ・開く（PC のみ。たたんでいる間は、選んでいるキャラの名前を見出しに出す） |
| `Ctrl+Z`（Mac は `⌘Z`） | 元に戻す |
| `Ctrl+Shift+Z` / `Ctrl+Y`（Mac は `⌘⇧Z` / `⌘Y`） | やり直す |

## プライバシー

- **読み込んだ画像はすべてブラウザ内で処理され、どこにもアップロードされません**
- 保存先も、手元のブラウザと書き出したファイルだけです
- アクセス解析のため [Google Analytics](https://policies.google.com/technologies/partner-sites) を使っています。ページの閲覧状況（アクセス日時・参照元・ブラウザの種類など）が、Cookie を使って Google に送信されますが、**画像やファイル名が送信されることはありません**
- フォントを [Google Fonts](https://fonts.google.com/) から読み込んでいます。この通信でも、接続元の IP アドレスやブラウザの種類が Google に渡ります

概要は、ツール内の右上の「？」（ヘルプ）の「プライバシー」でも読めます。

## 動作環境

- Chrome / Edge / Firefox / Safari の新しめのバージョン
- JavaScript が有効であること
- インストール・アカウント登録は不要
- 自動保存にブラウザの保存領域を使います。プライベートウィンドウなどで使えない場合は、自動保存だけが無効になります（他の機能は動きます）
- フォントはネット経由で読み込みます。読めない環境では端末のフォントになりますが、機能は変わりません

### スマホ・タブレットでも使えます

指でのタップと、**ドラッグでの移動・頭頂ライン／足元ラインの調整**に対応しています。画面が狭いときは、**盤面が上、道具の段と一覧・設定が下**の縦並びに切り替わります。

下半分は **「キャラ一覧」と「キャラ設定」をタブで切り替え**ます。右端の `⌄` で**タブだけ残してたたむ**と、盤面が画面のほとんどになります。縦向きのタブレットでは一覧と設定が左右に並び、「キャラ設定」の右端の `⌄` で**見出しだけ残してたためます**。たたんだ状態は、このブラウザに覚えておきます。

- **2 本指のピンチで拡大縮小できます。** そのまま 2 本指を滑らせると、倍率を変えずに盤面だけを動かせます
- **盤面を送りたいときは 2 本指が確実です。** 1 本指だと、キャラの上をなぞったときにそのキャラが動きます（動かしかけていても、2 本目の指を置いた時点で元に戻ります）
- 一覧の行は、**長押ししてから上下に動かすと重なり順を入れ替えられます。** ふつうになぞれば一覧が送られます
- 横向きにすると、一度に見える人数が増えます

ただし**広い画面の方がずっと快適です。** 何人も横に並べて見比べるツールなので、基本的には PC をおすすめします。

### 一度に並べられる人数

**同時に表示するのは 50 体程度までを目安にしてください**（快適に動く数は端末によって違います）。

動作に影響があるのは**同時に表示している数**だけで、**入れている数は関係ありません**。大人数を入れる場合では、一覧の目のアイコン（表示・非表示）で必要なキャラだけを出してください。100 体入れたままでも、表示が数体なら軽さは変わりません。

実際に重くなったときは、ツールからも一度知らせます。

### オフラインで使う

このページの `index.html` を保存すれば、ダブルクリックで開いて使えます。その場合、アクセス解析の通信は発生しません。

**ただしフォントだけは Google から読み込みます。** ネットに繋がっていなければ端末のフォントになり、機能は変わりません。また、自動保存は使えなくなることがあります。
